# Casted Materials

Lightweight Minecraft 1.21.1 NeoForge library for rendering one registered
block or item with material textures discovered from paired `#create:casing`
item and block tags.

The Java runtime is designed for Jar-in-Jar embedding.

## Blockbench authoring tools

The zero-install development workflow, examples, and tests live in
[`tools/blockbench`](tools/blockbench/README.md). They are excluded from the production JAR.
